# Использование

## Вход и первая синхронизация

1. Установи приложение из исходников: [Windows](../desktop/README.md) или
   [Android](../android/README.md).
2. Открой «Аккаунт → Войти через Яндекс». Подтверди вход на официальном сайте;
   пароль вводится там. Вход на ПК и телефоне выполняется отдельно.
3. В настройках выбери папку для музыки. На Android предоставь приложению
   доступ к папке через системное окно выбора.
4. Нажми синхронизацию в библиотеке.

Приложение сохраняет доступные полные MP3 из избранного. Для подписочного
контента нужен активный Плюс. Оно выбирает наибольший доступный битрейт MP3
и не перекодирует аудио. Если полная запись недоступна, это видно в библиотеке.

## Библиотека и файлы

Поиск работает по названию, исполнителю и альбому. Фильтры показывают всё
избранное, скачанные песни, оставшиеся загрузки или архив. Повторная
синхронизация проверяет избранное и дополняет библиотеку; подходящие
сохранённые файлы повторно не скачиваются.

Если база пустая, но в выбранной папке остались прежние экспорты приложения,
синхронизация распознаёт их по точному имени с ID трека, совпадению тегов
названия, исполнителя и альбома, а также проверке MP3 и длительности.
Подходящий файл отмечается скачанным без повторной загрузки и изменения байтов.
Windows проверяет подкаталог `account_<UID>` выбранной папки, Android — саму
выбранную папку. Если база сохранила прежнюю контрольную сумму, она также
должна совпасть; изменённый файл не получает новую сумму автоматически.
Сохранённая копия также распознаётся, если песня теперь недоступна в Яндексе,
но данных достаточно для проверки. Без подходящего локального файла такой
трек остаётся недоступным.

После утраты базы прежней контрольной суммы нет: распознавание устанавливает
новую сумму для подходящего файла, но не доказывает, что его звук совпадает
с оригиналом сервиса. Одноимённые файлы с неподходящими тегами или повреждённым
MP3 сохраняются без перезаписи и показываются как ошибка.

Обложки и метаданные записываются в ID3. В папке создаётся плейлист
`Мне_нравится.m3u8`.

**Тексты песен — WIP.** Сейчас получение не работает надёжно: Яндекс
нестабильно отдаёт тексты, а для части треков не отдаёт их вообще. Включённая
настройка не гарантирует, что текст подтянется. Если его удалось получить,
он сохраняется в MP3 и соседний `.txt`, синхронный — также в `.lrc`.
Загрузка музыки работает независимо от получения текста.

Windows открывает песню в назначенном внешнем плеере. Android воспроизводит
её внутри приложения и показывает элементы управления в уведомлении.

Остановленная загрузка сохраняет прогресс. Приложение не перезаписывает
посторонние одноимённые файлы. При смене папки можно перенести сохранённую
музыку или выбрать новое место только для следующих загрузок.

## Архив и ошибки

После снятия лайка песня перемещается в архив при следующей синхронизации.
Отдельную запись можно скрыть, архив — очистить. Файлы остаются в папке;
если снова поставить лайк, приложение возвращает запись и повторно использует
подходящий файл. Скрытие записей можно отменить.

Нескачанные песни остаются в соответствующем фильтре. Синхронизация повторяет
неудачные загрузки, до трёх проходов за запуск. Закрытие итоговой карточки
скрывает сообщение, но не удаляет песню и не мешает следующей попытке.

## Автоматическая проверка

Она выключена по умолчанию. В настройках можно включить проверку каждый час,
каждые 6 часов или раз в день, а также ограничить загрузку Wi-Fi.

- **Windows:** работает, пока приложение открыто, включая свёрнутое окно.
  Закрытие окна завершает работу после сохранения текущего состояния.
- **Android:** используется системный JobScheduler. Задача может запускаться
  позже выбранного интервала из-за ограничений батареи, сети или оболочки
  телефона. Ручная загрузка может продолжаться с уведомлением.

Ручная синхронизация доступна независимо от расписания.

## Тема

Есть тёмная, светлая и системная темы. Windows использует акцент системы;
Android в режиме «От телефона» использует Material You, если устройство
поддерживает динамические цвета.

## Аккаунт и данные

Если вход истёк, повтори его на вкладке «Аккаунт». Также можно вставить
собственный токен в скрытое поле. На Windows CLI-команда `token` читает его
через `getpass`, без аргумента командной строки.

Профиль со скачанной музыкой привязан к аккаунту: вход с другим UID
отклоняется. Для проверки другого аккаунта используй отдельный профиль данных.

На Windows база, настройки, токен и кеши лежат в
`%LOCALAPPDATA%\YaMusicDownloader`. Токен хранится в локальном JSON без
собственного шифрования. Переменная `MUSIC_DATA_DIR` задаёт отдельный каталог
для разработки. На Android токен шифруется AES-GCM с ключом в Android Keystore;
служебные данные находятся в приватной папке приложения.

Debug APK использует отдельный пакет и отдельные данные. Выбери для него
отдельную папку музыки при проверке рядом с основной установкой.
