# Android

Нативное приложение «Моя музыка», Java и Material 3. Android 8.0+ (API 26).

Готовый APK — в
[релизах](https://github.com/Holorigg/ya-music-downloader/releases/latest).
При обновлении установи его поверх прежней версии.

## Совместимость

| Требование | Поддержка |
|---|---|
| Система | Android 8.0 и новее, минимум API 26 |
| ARM64 (`arm64-v8a`) | Современные Android-телефоны; один общий APK |
| 32-битный ARM (`armeabi-v7a`) | При наличии Android 8.0+ |
| x86 / x86_64 | Совместимы по архитектуре; на устройстве и в эмуляторе пока не проверены |
| Google Play Services | Не требуются |
| Интернет | Для входа и синхронизации; сохранённые MP3 воспроизводятся офлайн |
| Хранилище | Папка с доступом через системный выбор документов и место для MP3 |
| Динамические цвета | Android 12+ и поддержка Material You прошивкой |

Модель процессора сама по себе не ограничивает установку. Snapdragon,
MediaTek, Exynos, Kirin, Tensor и Unisoc подходят при совместимой системе.
Java-код и зависимости приложения не включают нативные `.so`, а сборка
не делится по ABI. Поэтому APK не требует отдельной версии под каждый чип.
Основание: [совместимость Java-приложений](https://developer.android.com/google/play/requirements/64-bit),
[архитектуры Android](https://developer.android.com/ndk/guides/abis).

Основные сценарии версии 2.0.1 проверены на **Honor 200**. Таблица описывает
совместимость сборки; она не означает, что каждый процессор и каждая прошивка
проверены на устройстве. Интерфейс рассчитан на телефоны; отдельной адаптации
для Android TV и Wear OS нет.

## Первый запуск

1. Установи APK. Разреши установку из выбранного источника, если Android попросит.
2. На вкладке «Аккаунт» выбери «Войти через Яндекс» и подтверди вход на официальном сайте.
3. В настройках выбери папку, например `Music/Моя музыка`, и предоставь доступ.
4. Запусти синхронизацию в библиотеке. На Android 13+ приложение запросит
   разрешение на уведомления о прогрессе синхронизации.

Если в папке уже есть MP3 с точным именем песни, приложение может принять его
после проверки ID в имени, ID3-тегов исполнителя, названия и альбома, а также
полной длительности. Для сохранённой записи приложение использует её прежние
имя и документ в выбранной папке: совпадающая контрольная сумма позволяет
восстановить запись даже после обновления метаданных каталога. Файл не
перезаписывается; несовпавший или повреждённый MP3 останется на месте.
Для песни, отмеченной каталогом как недоступная, приложение проверяет только
локальный экспорт и не запрашивает её загрузку.

На Android 11+ системный выбор ограничивает доступ к корню накопителя,
корневой папке Downloads и каталогам `Android/data` и `Android/obb`.
Используй отдельную папку в Music:
[правила системного выбора папок](https://developer.android.com/training/data-storage/shared/documents-files#document-tree-access-restrictions).
Некоторые облачные провайдеры папок не поддерживают нужное переименование;
для таких случаев выбирай локальную папку.

Автосинхронизация выключена по умолчанию. При включении Android планирует
задачу через JobScheduler; выбранный интервал приблизительный. Если прошивка
ограничивает приложение в фоне, проверь её настройки батареи и фоновой работы.
Тёмная и светлая темы доступны на всех поддерживаемых версиях Android.

**Тексты песен — WIP:** получение пока нестабильно и может не сработать
даже при включённой настройке. Яндекс не всегда отдаёт текст;
скачивание MP3 от этого не зависит.

## Сборка

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Установи их через
Android Studio / SDK Manager. Укажи путь SDK в `ANDROID_HOME` или локальном
`local.properties` (`sdk.dir=...`); этот файл не попадает в Git.

Из каталога `android`:

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintRelease
```

На Linux/macOS: `sh gradlew :app:assembleDebug`.

Debug APK: `android-app/build/outputs/apk/debug/app-debug.apk`. Он имеет
отдельный пакет `ru.holorigg.musicsync.debug` и имя «Моя музыка · Dev», поэтому
устанавливается рядом с обычным приложением и использует отдельные данные.
В dev-версии выбери отдельную папку для пробной загрузки.

Первый запуск wrapper загружает Gradle 8.13. Контрольная сумма дистрибутива
зафиксирована. JDK/SDK/Gradle-кеши и готовые APK в исходники не входят.

## Подпись release

`assembleRelease` собирает неподписанный APK. Для распространения подпиши
его своим ключом через Android Studio или `apksigner`. Ключ, пароль и signing
файлы не коммить. Обновление существующей release-установки требует прежнего
ключа; debug APK её не заменяет.

## Проверки и руководство

Настройки, архив и тексты: [инструкция](../docs/usage.md).

JVM-проверки работают без токена и аккаунта. Отрисовки используют только
демонстрационные данные; Robolectric не воспроизводит оболочку телефона.
SAF, Keystore, уведомления и ограничения фоновой работы дополнительно
проверяются на устройстве.
